# Image attribution plan

Created before reading images. 399 g-band field770 images selected from the exact accepted photometric detections. In each of20 frozen-period phase bins, choose at most15 discovery and5 validation exposures evenly in chronological rank, without using measured brightness. All chosen entries and URLs are in the CSV. Query60-arcsecond cutouts for difference and science images, with associated difference PSFs; first validate a small API sample. Maximum download size2MB each prevents accidental full-image retrieval. Record raw SHA256 hashes, shape/header checks and failures.

Image attribution is an exploratory follow-up to the existing photometric selection, not an independent variability discovery. White dwarf proper motion, subtraction dipoles, changing references, nearby stars, seeing, background and image alignment must be accounted for. The frozen frequency and phase are retained. A signal outside the white dwarf position invalidates a white-dwarf attribution.

API source: https://irsa.ipac.caltech.edu/docs/program_interface/ztf_metadata.html
